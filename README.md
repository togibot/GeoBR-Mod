# GeoBR Mod

The official GeoBR community hub for Geometry Dash, built with the Geode SDK.

## Update 1.0.0

- GeoBR button added to the Geometry Dash main menu
- Initial GeoBR Hub entry point
- Initial sections planned for Profile, Ranking, Events, Creator Battles and Badges
- Cross-platform GitHub Actions build

## Build

This repository uses the official Geode build action to build Windows, macOS, iOS, Android32 and Android64 packages through GitHub Actions.
